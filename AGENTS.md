
# AGENTS.md — Romina XV

## Identidad del proyecto
Landing page premium para los XV años de
Lia Romina Santos Enriquez.

Proyecto independiente, sin relación técnica
con otros sistemas de invitaciones.

## Metodología
Aplicar MIDE-IA 2.0:
- Análisis antes de implementación.
- Desarrollo por fases.
- Validación por fase.
- Evidencia de pruebas.
- Commits con cambios verificables.

## Stack aprobado
- React
- TypeScript
- Vite
- GSAP y ScrollTrigger
- CSS modular
- Embla Carousel
- GitHub Pages

## Reglas
1. Respetar el diseño visual aprobado.
2. Implementar mobile-first.
3. Conservar las fotografías originales.
4. No alterar rasgos físicos.
5. No inventar datos del evento.
6. Mantener los datos centralizados.
7. No incorporar backend ni base de datos.
8. No instalar dependencias innecesarias.
9. No subir secretos ni archivos privados.
10. Respetar prefers-reduced-motion.
11. Mantener animaciones optimizadas.
12. Verificar builds, enlaces y pruebas.
13. No publicar sin autorización explícita.
14. No eliminar archivos originales.
15. Documentar decisiones y limitaciones.

## Ejecución
Cada fase debe terminar con:
- Resumen de trabajo.
- Archivos modificados.
- Pruebas y resultados.
- Riesgos o pendientes.
- Recomendación de siguiente fase.

Detenerse al completar cada fase.
No avanzar automáticamente a la siguiente.
